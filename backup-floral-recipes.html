Back up and move your floral recipe library

Local storage keeps recipes available without an account. A separate export gives you a file you can keep, copy, and use to move the library to another iPhone.

By Gilad Ronen · Updated October 20, 2026

Know which copy you have

PetalPull stores active recipes and photos in its private iOS app container. It does not upload or sync the library to a developer-operated service. iOS may include app data in a device or iCloud backup according to your system settings; that is separate from PetalPull's manual JSON export.

A PDF recipe card is useful for reading or printing a design, but it is not the portable library backup used to restore editable recipes.

Export a library backup

  1. Open Backup & restore in PetalPull.
  2. Choose Export JSON backup.
  3. Use the iOS sharing interface to save the file somewhere you control, such as a chosen Files location.
  4. Keep the filename and date clear so you can identify the newest library copy.

The versioned JSON backup can include reference photos. Store it with the same care as the recipes themselves, particularly if notes or images contain private client or business details.

Move to another iPhone

  1. Export a current backup on the original device.
  2. Copy the file to a location accessible from the destination iPhone.
  3. Install PetalPull and open Backup & restore.
  4. Choose the exported file. Read the confirmation carefully: restoring replaces the local library rather than merging it.
  5. After restoration, check several recipes, their material quantities, notes, and attached photos.

Before replacing an existing library

If the destination already contains work you need, export that library first. Keep the two exports distinguishable. Do not assume the import merges them or that a file saved on the phone will survive deleting every associated copy.

Before deleting or changing devices

Deleting PetalPull removes its active local app container. Make and verify the export before removing the app or relying on a new phone. OS-managed backups and files you previously exported are separate copies and follow their own retention settings.

Check a backup as part of your routine

After adding a collection of recipes or completing a busy production period, save a new export. On the destination, inspect the restored work before discarding the original device or older verified copy. A useful check is a recipe with a photo, several materials, and production notes.

For camera, printing, or import questions, visit PetalPull support. The privacy policy explains local storage and system backup behavior in more detail.
